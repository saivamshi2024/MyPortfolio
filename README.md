## Run locally

You need **Node.js** and **npm** installed.

```bash
git clone https://github.com/saivamshi2024/MyPortfolio.git
cd MyPortfolio
npm install
npm start
```

The app opens at `http://localhost:3000`.

## Customize

Most content lives in `src/portfolio.js`:

- Name, nickname, and subtitle
- Social links
- Skills
- Education, experience, projects
- Contact details

Theme colors are in `src/theme.js`.  
Page title and meta tags are in `public/index.html`.

### GitHub project data (optional)

1. Copy `env.example` to `.env`
2. Add `GITHUB_USERNAME` and `GITHUB_TOKEN`
3. Run:

```bash
node git_data_fetcher.mjs
```

## Build

```bash
npm run build
```

Deploy the `build` folder (GitHub Pages, Netlify, or similar).
